# DayOne 🌱

Um aplicativo simples para acompanhar a jornada de parar de fumar, celebrar cada conquista e visualizar a evolução ao longo do tempo.

Este é um projeto pessoal criado por mim, Adriana Oliveira, para acompanhar a minha própria jornada sem fumar.

O aplicativo foi desenvolvido com a ajuda do GPT. Eu trouxe as ideias e defini o que gostaria de criar e, ao longo do processo, fui testando, ajustando e aprimorando os códigos até chegar ao resultado desejado.

A proposta é transformar cada dia sem fumar em algo visível e significativo. 
O DayOne acompanha o tempo desde o último cigarro, a quantidade de cigarros evitados, o dinheiro economizado e os benefícios conquistados ao longo dessa nova fase.

Também celebra os marcos da jornada, porque cada dia importa e cada conquista merece ser reconhecida.

Um dia de cada vez. Uma conquista de cada vez. 🌱
